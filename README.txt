موقع حب إلى نُوشي ♡
====================
طريقة التشغيل:
1. فك ضغط ملف Noshy-Love-Site.zip.
2. افتح مجلد Noshy-Love-Site.
3. افتح index.html باستخدام Chrome أو Edge.
4. اترك ملفات index.html وstyle.css وscript.js في نفس المجلد.

الموقع يعمل محليًا دون تثبيت. الاتصال بالإنترنت مطلوب فقط لتحميل الخطوط المخصصة؛
وعند عدم توفره سيستخدم المتصفح خطوطًا بديلة.
